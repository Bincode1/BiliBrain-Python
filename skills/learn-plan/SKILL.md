# 规范学习路线生成技能 (Skill-Learning)

## 技能描述
本技能用于根据用户的学习目标、当前水平和可用资源，自动生成结构化的、可执行的学习路线。它特别适用于技术栈学习、证书备考或特定领域知识体系的构建。

## 核心能力
1. **需求分析**：解析用户的目标（如“掌握 Python 数据分析”）、当前基础和时间约束。
2. **资源映射**：结合知识库（视频摘要、具体知识点）和外部资源，匹配最佳学习材料。
3. **路径规划**：生成分阶段的学习计划，包含：
   - **阶段划分**：基础 -> 进阶 -> 实战 -> 拓展
   - **关键节点**：每个阶段的核心知识点和里程碑
   - **时间估算**：建议的学习时长和节奏
   - **实践任务**：配套的练习项目或实验
4. **动态调整**：根据用户反馈或进度，优化后续学习路径。

## 工作流程
1. **激活技能**：用户明确请求生成学习路线时，先激活本技能。
2. **信息收集**：
   - 询问学习目标、当前水平、可用时间、偏好学习方式（视频/文档/实战）。
   - 确认是否需要覆盖特定工具、框架或认证考试。
3. **知识检索**：
   - 使用 `search_video_summaries` 获取相关视频的整体概览和推荐顺序。
   - 使用 `search_knowledge_base` 查询具体知识点的定义、步骤和细节。
   - （可选）使用 `web_search` 补充最新的技术趋势或官方文档链接。
4. **路线生成**：
   - 结构化输出学习路线，包含阶段、主题、资源链接（带编号引用）、实践建议。
   - 标注重点难点和前置依赖关系。
5. **文件保存**：将生成的学习路线保存为 Markdown 文件（如 `learning-path-<topic>.md`）到指定目录。
6. **验证与迭代**：允许用户对路线提出修改意见，进行局部调整。

## 输出规范
- **格式**：Markdown，清晰的分层结构（标题、列表、代码块）。
- **引用**：所有基于知识库的内容必须附带资料编号，如【1】【2】。
- **可操作性**：每个阶段必须有明确的“完成标准”或“检查点”。
- **灵活性**：提供“快速版”和“深度版”两种节奏供用户选择。

## 示例输出结构
```markdown
# 学习路线：Python 数据分析

## 🎯 目标
掌握使用 Python 进行数据清洗、分析和可视化的核心技能，能够独立完成 Kaggle 入门级项目。

## 📊 当前水平评估
- 假设用户具备基础 Python 语法知识。
- 无 Pandas/Matplotlib 经验。

## 🗓️ 阶段规划

### 阶段 1：基础工具入门 (预计 1 周)
- **核心内容**：
  - Pandas 数据结构 (Series, DataFrame) 【1】
  - 数据读取与导出 (CSV, Excel) 【2】
- **推荐资源**：
  - 视频：Pandas 基础教程 (收藏夹: Agent技术) 【3】
  - 文档：官方 Pandas User Guide
- **实践任务**：
  - 加载一个 CSV 文件并打印前 5 行数据。
  - 筛选出满足特定条件的数据行。
- **完成标准**：能独立读取数据并进行简单筛选。

### 阶段 2：数据清洗与处理 (预计 2 周)
...

## 🛠️ 实战项目
- 项目 1：泰坦尼克号生存预测数据探索
- 项目 2：电商销售数据分析

## 🔄 复习与拓展
- 每周回顾笔记
- 关注社区最新案例
```

## 注意事项
- 若知识库中缺乏特定领域的视频资料，需明确告知用户并建议补充外部资源。
- 避免生成过于理论化的路线，必须强调“动手实践”。
- 对于复杂技能树，可拆分为多个子路线文件。
